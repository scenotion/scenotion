# Localization

Status: v0.1 i18n foundation. Last updated: 2026-10-27.

## Locale resolution

Locale priority:

1. URL query: ?locale=zh-CN
2. localStorage: scenotion.videoLocale
3. Default: en-US

The editor locale and the video locale will be separate. This layer is the video
locale used by scenes and AutoText.

    import { localeSignal, setLocale, t } from "../i18n";

    setLocale("zh-CN");
    const title = t("codeWorkflow.title");

Templates can interpolate named values:

    formatMessage("Hello {name}", { name: "Scenotion" });

## Catalogs

Catalogs live in:

    src/i18n/catalogs/en-US.ts
    src/i18n/catalogs/zh-CN.ts

en-US defines the key set. zh-CN is typed as Record<MessageKey, string>, so a
missing or extra key fails TypeScript. Add a key to both files in the same change.

Use flat, feature-prefixed keys: codeWorkflow.title, status.source, frame.meta.

## Scene text

SceneFrame accepts strings or signal functions. Use a function for anything that
must react to locale changes:

    <SceneFrame title={() => t("codeWorkflow.title")} ... />

Calling t() inside a signal supports Motion Canvas dependency tracking, so the
text can update when the locale signal changes.

## AutoText

AutoText measures and wraps text for the current width, then shrinks the font
until it fits maxLines. It handles Latin words and CJK characters. If even the
minimum size does not fit, the last line is truncated with an ellipsis.

    <AutoText
      keyPrefix="scene-title"
      text={title}
      width={1728}
      maxLines={2}
      fontSize={112}
      minFontSize={64}
      lineHeight={1.08}
      fontFamily={theme.font.sans}
      fontWeight={800}
      fill={theme.text}
    />

keyPrefix must be unique within a scene. It is used for the child Txt keys.

## Fonts

Fonts are project assets. Scenotion does not ship or manage fonts. A project may
load a cloud font, an npm font package, or a local font file. Local font files are
ignored by Git. Scenotion only waits for the project font to load before rendering.

## Tests

Current tests cover locale parsing, catalog parity, interpolation, text layout and
the editor UI dictionary. Visual scene checks are manual for now; browser automation
is planned.
## Editor UI

The editor is a local package in editor/ and is selected with editor:
"@scenotion/editor" in vite.config.ts. It uses the targeted @scenotion/ui fork from
packages/scenotion-ui. No node_modules patching is involved.

- editor/i18n.ts installs a Preact options.vnode hook for Chinese.
- editor/plugin.ts adds the Scenotion sidebar tab.
- UI locale: ?ui=zh-CN, or the Scenotion tab. Stored as scenotion.editor.locale.
- Video locale: ?locale=zh-CN, or the Scenotion tab. Stored as scenotion.videoLocale.
- The vnode hook translates string children, title, placeholder, aria-label and
  known attributes. Unknown strings and user project names are left alone.
- The dictionary lives in editor/i18n.ts. Add a key there for new UI chrome.
- The forked timeline adds a narration lane; its labels are intentionally minimal
  and can move into the UI dictionary when the track UI is expanded.

Switching a language reloads the editor. This keeps stock Motion Canvas state
predictable and avoids partial re-renders.
